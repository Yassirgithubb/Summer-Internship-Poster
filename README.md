
# 🧪 Characterization and Optimization of Droplet Sorting Technique in Microfluidics

![Poster](image.png)

## 📌 Project Overview

This repository contains the poster I presented at the end of my internship, titled **"Characterization and optimization of droplet sorting technique in microfluidics"**. The project was conducted under the supervision of **Jiande Zhou** and **Philippe Renaud** and aimed at optimizing the encapsulation of single cells within microfluidic water droplets.

### 🔬 Background

Microfluidic droplets provide an excellent platform for compartmentalizing and isolating biological or chemical content, particularly in biomedical applications. This project focused on:
- Controlling the size and speed of microdroplets
- Maximizing the number of droplets containing single cells
- Understanding the influence of cell confluency and flow rate on droplet formation

### 🧫 Experimental Highlights
- Use of **HEK cells** due to their reliable growth and behavior
- Experiments tuned for optimal confluency (70–80%) for proper single-cell encapsulation
- A custom **PDMS microfluidic chip** used for generating and spacing droplets using two oil inlets
- Flow rate carefully adjusted via **triple syringe pump control**

### 📈 Results Summary
- Graphs demonstrate how droplet speed, size, and spacing depend on flow rate and channel dimensions
- Key findings:
  - Droplet size is tunable by adjusting the width of the generation channel
  - Droplet spacing is controlled using the second oil inlet
  - Droplet speed increases with total flow rate and varies with channel height

### ⚙️ Technical Notes
- Main experiment components:
  - Triple syringe pump for precise flow control
  - Two oil inlets: one for droplet generation, one for spacing
  - Adjustable generation channel width and height

### 📚 Conclusion

This internship provided hands-on experience with microfluidic systems and taught me valuable skills in cell culture, chip design, and experimental planning.
